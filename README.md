# Graveyard Kit 🪦

Find the dead packages in your codebase, swap each one for a living replacement, and **prove** with property-based tests that your code still behaves the same.

- `skeleton/`: the reusable kit (adapter interface, death score, proof harness, graveyard UI)
- `apps/exorcist-npm/`: Exorcist for npm, the flagship app

Built with [Kiro](https://kiro.dev) for Kiroween 2026. See `.kiro/` for the specs, steering, hooks and agents used to build it, and `docs/kiro-log.md` for the build log.
