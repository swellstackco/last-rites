# Toe Tag redesign: visual check, 2026-11-13 (Claude)

Headless Chromium at 1352x800 and 390x844 after 6f860b4, against the mockups in docs/design/. The direction works (steel wall, manila tags on strings, form-grid breakdown, hanging tag in the panel header). No console errors, no horizontal scroll. Defects:

T1. Proof hidden for the best demo: the controller only requests a Proof_Report for grades `dead` and `dying` (apps/exorcist-web/src/app/controller.ts proofFor). `intersect` (parse-server, grade ailing, score 35) has a real report with attempt 1 counterexample and attempt 2 proved, but its panel shows no Proof_Section at all. Expected: request the proof for any grade of a demo package; a missing report keeps today's "no proof yet" behavior (only shown for dead/dying, as now), so ailing/alive panels without a report look unchanged.
T2. Grade on the tag is a small centered chip ("DEAD 75-100"). Expected per mockup: a full-width colored band along the tag's bottom edge, grade word left in display caps, one short fact right (e.g. band range or "0 maint."), edge to edge inside the tag border.
T3. Tag field alignment is mixed: short package names and the SCORE block are centered while long names and CAUSE are left-aligned. Expected: every field (PACKAGE, SCORE, CAUSE) left-aligned on ruled field lines, score number left-aligned and large, as in the mockup.
T4. Header subtitle "OFFICE OF THE DEPENDENCY EXAMINER · FORM LR-1" wraps so "LR-1" sits alone on a line (desktop and mobile). Expected: no orphan; keep "FORM LR-1" together (non-breaking) and let the subtitle wrap only between phrases.
T5. Home page has no masthead: a small "The Graveyard" eyebrow and a small "LAST RITES" heading, unlike the graveyard page's big condensed masthead. Expected: the same masthead as the graveyard page (big LAST RITES + examiner subtitle), then one plain pitch line: "Find the dead npm packages in a repo, swap them out, and prove the new code behaves the same." Demo cards become hanging toe tags (string + punched hole) and show each demo's dead count from its snapshot when available (fallback: the existing blurb only).
T6. Scan form: "Branch or tag (optional)" label is drawn inside a bordered box so it reads as a broken input. Expected: the same typewriter field label style as "REPOSITORY" above its own input.
T7. Mobile (390px): tags are 2-up, so long names wrap into 4 lines and break mid-word ("@saithodev/sem / antic-release-backmerge"). Expected: 1-up tags below 520px; package names may break only after "/" or "-" (use <wbr> after those characters or equivalent), never inside a word.
